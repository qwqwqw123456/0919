# 高风险操作前置清单

把"安全"从纸面规则变成每次写操作前必过的强制清单 + 留痕协议。适用：所有会对外生效、不可逆或影响用户资产的写操作。

## 四类高风险动作（命中即触发确认 + 留痕）

| 类别 | 具体动作 | 动手前必须回答 |
|---|---|---|
| D-删除 | 删除/覆盖/移动用户文件、画布对象、飞书文档/消息/日程、git 破坏性操作（reset --hard） | ①对象是用户资产吗？②备份过、能恢复吗？③用户明确授权了吗？ |
| S-对外发送 | 发消息/邮件/群发/审批提交/会议操作/发布内容 | ①接收方与内容用户确认过吗？②能撤回吗？③文案是终稿吗？ |
| P-付费/权益 | 付款/下单/充值/兑换/开通订阅 | ①金额与账户确认过吗？②能退吗？③预算告诉用户了吗？ |
| A-权限/迁移 | 权限变更、数据迁移、批量下载/上传、敏感信息导出 | ①影响范围用户知道吗？②可逆吗？③碰隐私红线了吗？ |

## 留痕协议

命中任一类，台账条目必须包含：

```
- **操作留痕**：类别[D/S/P/A] · 对象 <id/路径> · 结果 <成功/失败> · 确认依据 <用户指令原文/等待中>
```

## 执行纪律

1. 高不可逆风险（删除无备份、对外发送、付费）→ 先确认再动手，确认依据写进留痕
2. 低风险本地可逆（新建文件、跑本地脚本、只读查询）→ 不触发本清单，直接执行
3. 未获确认前，不得以"自主权"为由越过本清单——自主权不豁免安全线
4. 凭证、Token、证件号一律脱敏：只显前 4 后 4，中间打码，不入文件、不入聊天

## 交付前必过三问

- [ ] **计划显式化**：任务超过 3 步或跨技能时，我有没有先把 3–5 行计划摆出来？
- [ ] **跑过真东西**：写了代码/脚本/产物，我有没有真跑一次构建或执行？失败自己修，最多 3 轮。
- [ ] **成品门**：交付物是用户能直接打开用的最终形态，还是骨架/教程/占位？后者不许交。

## 边界（别装成内核钩子）

本清单是**人工强制对照协议 + 留痕审计**，不是内核级强制拦截：本运行时没有硬钩子，靠每次动手前调用 `pre-write-check` 技能做扫描，靠台账做事后可审计。
